## 📖 项目概述

一个基于 **Vue 3** 的内容管理系统，支持用户管理和谜题发布功能。

---

## 🛠️ 技术栈

| 类别 | 技术 |
|------|------|
| 框架 | Vue 3 + Vite |
| UI 组件库 | Element Plus |
| 状态管理 | Pinia |
| 路由 | Vue Router |
| 富文本编辑器 | Quill |

---

## ✨ 功能模块

### 👤 用户管理

| 功能 | 说明 |
|------|------|
| 🔐 登录 / 退出 | 用户身份认证 |
| 🖼️ 头像上传 | 自定义个人头像 |
| 🔑 密码修改 | 更新登录密码 |
| 📝 个人资料编辑 | 修改用户信息 |

### 📄 文章管理

| 功能 | 说明 |
|------|------|
| 📋 文章列表 | 分页展示所有文章 |
| ✍️ 文章发布 / 编辑 | 富文本编辑，支持图文混排 |
| 📂 频道分类 | 文章归类管理 |
| 🖼️ 封面图片 | 上传文章封面图 |

---
